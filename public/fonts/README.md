Self-hosted fonts, picked up by the @font-face rules in src/styles/global.css.

- apercu-regular.woff2, apercu-medium.woff2, apercu-bold.woff2: Apercu (Colophon Foundry),
  licensed for web use. Converted from the desktop .otf files with fontTools.
- holiday-journey-regular.otf: Holiday Journey (Calamar Studio), the logo typeface, used for headings.

If the Apercu files ever fail to load, the site falls back to Figtree from Google Fonts.
